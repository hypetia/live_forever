Windows：完整解压游戏包，双击 `LiveForever.exe`；Linux运行 `LiveForever.x86_64`。不需要安装Godot或Python。新营地机制请新开战役，游戏内O装备、K制作、F5管理营地，F6保存、F9读档、F11全屏。

源码使用Godot4.6.3标准版导入 `project.godot`。对应源码提交：[0b1eff4](https://github.com/hypetia/live_forever/commit/0b1eff4f23903f91f4472d6bea7d4d346cb1eea4)。

Windows真机尚待验收；可选验收包包含主游戏、独立验收程序和脚本，解压后运行 `windows_acceptance.cmd`，默认约30分钟。结果保存在 `AcceptanceResults-*` 文件夹，可压缩发回。普通试玩只运行主游戏。
