# 人物系统 · v0.6

## 角色与队伍

初始仍是林舟、许遥、陈野。第3、6、9天可分别遇到沈禾、顾苒、唐弥，每人仅能加入一次；需要至少一级据点，支付生食2、水2、药品1。最多五人存活在队，最多保留六位不同人物的记录。已故成员永久保留身份与伤亡记录，不会被新来者复活。

| 人物 | 专长与实际效果 | 弱点 / 倾向 |
| --- | --- | --- |
| 林舟 | 工匠；修整4.5秒、制作6秒；工艺经验+20% | 疲劳85以上额外积累压力 |
| 许遥 | 医护；治疗6秒，可援助队友；失去队友时压力+15，其他人通常+25 | 队友生命低于40时更易担忧 |

| 顾苒 | 医护；治疗6秒、援助队友，照护经验+20% | 非睡眠疲劳增长+10% |

基础配方和产量相同，专长不提供免费物资。人更多意味着更多进食、饮水、床位与设施等待。

## 有上限的成长

工艺、照护、探索各为0—3级，累计30、90、180经验升级，经验最多180。每级提高对应进度速率5%，最多15%；任务定义耗时保持不变，现有工作和存档无需重置进度。

- 工艺：完成修整6经验、制作8、做饭4；林舟额外20%。
- 照护：完成治疗8、实际医疗援助8；顾苒额外20%。
- 探索：从容器真正装入每份物资2经验，成功带回净补给另加4。

取消、失败、空容器、只带原装备往返都不能刷完成奖励。吃饭和睡觉没有可免费反复刷取的经验。探索成长改善搜索和脚步声，不增加敌人血量、不取消工具消耗，也不提高背包容量。

## 可解释的情绪和关系

心境越高越好，压力 / 创伤越低越好。严重饥渴、疲劳、伤势、感染、长时间独行会增加压力；扑咬还增加压力8、创伤2、降低心境2。充分进食、休息、治疗、安全归来和照顾同伴帮助恢复。

心境低于25、压力达到80分别让效率乘0.9；不会随机拒绝命令、消失或自杀。恢复任务不受这些降速拖慢。创伤达到40后增加持续压力，良好生活、支持和医疗可以缓解。

失去队友让存活者心境−18、压力通常+25、创伤+10；亲密关系（信任≥60）额外降低心境5。伤亡账目确保死亡、保存 / 恢复或重复清理不会再扣一次。

P人物页选择当前角色和同伴，可执行：

- **共餐安慰**：熟食1，两人心境+10、压力−20、创伤−8、信任+10；信任≥60时心境+15。每人180秒冷却，不代替日常进食。
- **医疗援助**：需要当前角色为医护、目标确实受伤且活着，药品1。目标生命+20至26（按医护照护等级）、伤势−40、感染−35，缓解压力 / 创伤；医护获得经验、双方信任+5。每人180秒冷却。

这两种是基地的直接管理行动。原来的餐桌治疗仍是可排队任务，生命 / 伤势恢复更充分。外出不能远程共餐、医疗援助或招募；现场仍用背包药品R。

## 饮水与照料授权

口渴默认20，每模拟秒+0.045；80起效率乘0.9，95起每秒伤生命0.06，有独立预警。水1降低口渴60。基地P人物页饮水，外出按B只能用本人背包中的水，不能远程拿基地库存。

逐人勾选“自动照料”后，才会按需要消耗基础物资：口渴60时饮水；本人空闲且饥饿60时排吃饭，缺熟食但有原料时排做饭→吃饭；疲劳65时排睡眠。饮水不打断正在进行的工作，其他照料复用设施FIFO，不替换已有任务。

授权默认关闭，新成员默认关闭；允许外出前授权的留守照料继续，不自动花药品 / 工具或升级。关闭后不再追加照料，已排入的任务可用Q取消。缺料明确显示等待补给，不能靠授权制造食物或水。

## 数据与持久化

`PeopleCatalog` 定义固定身份与机械差异；`CharacterState` 保存心境、压力、创伤、口渴、经验、加入日期、授权、共餐 / 援助冷却与预警。`PeopleSystem` 处理需求、照料、队友关系、伤亡、招募和日历账目。

调度器在真正完成和死亡时发信号；搜索只按实际取得数量奖励。根节点管理新增 / 重建人物、选择、卡片与场景切换。保存schema4扩展到3—6条身份记录、最多5位存活者，按人物身份验证专长耗时，并整体恢复设施、人物、关系与外出。

旧schema1/2/3迁移保留人物、库存、用料、工作、地图与伤亡，照料默认关闭；完成记录折算有限工艺 / 照护经验，探索历史无法按人确定时不伪造经验。旧档口渴初始化20、心境60、压力 / 创伤0，升级后暂停，不补算离线损耗。
