# 本作的可玩性目标

目标是做出有自身玩法、值得长期反复玩的僵尸生存游戏。评价依据是玩家面临的选择、场景操作和长期结果，而不是功能清单长度、自动测试数量或与成熟商业游戏相似的界面。

## 核心方向

1. **每次外出都有不同目的。** 争夺补给、改变通路、建立或维护前哨、压制街区压力、取得战役零件，争夺同一晚的时间、背包和工具。v1.9已把压力、前哨和声源接入真实行动。
2. **人物分工改变打法。** 速度与噪声、搬运、制作、医疗、轮值收益和休息需求要共同影响人选；强者也需要休息，新增人手会增加食物和安防压力。已有专长、情绪、关系、伤病、v1.9轮值和v1.10基本自理共同参与，仍需更多长期情境检验。
3. **世界记住行动，并提供反制。** 枪声留下街区压力，成功轮值提供短期控制，诱饵改变敌人的实际目标，现场整治与更换街区能缓解风险。结果应提前有可读信号，事后可复盘，不因玩家升级装备偷偷提高敌人血量。
4. **经营支持冒险。** 安全、生产、取暖和扩张争夺资源、人手与时间；维护和轮值持续付成本。v1.9已核对燃料、子弹、装备磨损、寒冷、死亡和单次结算。
5. **让场景承担交互。** 主画面用人物、物件、轮廓和进度反馈；Y街区图和其他面板按需打开。地图通路、容器、攻击与施工都需要真实距离，不能远程拿物资或瞬间完工。

## 距离目标仍需完成的工作

当前已有门窗潜入、亲自基地防守、三个开局、个人计划、协作和迁居。v1.13进一步把诊所与水厂接入有限搜刮、持续供给、分流、背负救援与行为记忆；两图使用专门安排的隔门，普通容器保持空。仍是两层横版，其余七图尚未接入这套补给改造，搬家后的布局差异和人物社会行为也仍需深化。不能把它描述成已经“超越《这是我的战争》”。

下一步应从本轮真实路线与真人反馈扩展地图的解法和长期后果；持续生产必须减少旧劳动，事件要有线索与应对，不能靠重复收费或装备越强敌人越厚维持难度。详见[第一片街区](NEIGHBORHOOD_V23.md)。

每轮应完成一条能实际游玩的新循环，附正常流程证据，修复回归并交付可运行包。一次演示成功和某个策略能通关，都不足以证明整体成熟度；需要持续试玩、修正与取舍。
