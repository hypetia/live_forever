# 长期循环：地点、维护与选择

## 每个地点是一份世界

`LocationCatalog` 只定义固定地图：容器、楼层边界、梯子、掩体、巡逻、色调与说明。根节点持有三份独立 `ExpeditionState`；`game.expedition` 引用当前选择的那份。其他地点不推进敌人动作，保留物资与击倒状态。

保存继续包含当前 `expedition`，另保存 `destination` 与其余两个 `other_regions`。不会把某一地点的容器套在另一张地图，也不重复持久化同一份状态。验证按各地点定义检查边界、容器容量和感染者数量；其他地点必须非活动，不能持有背包或另一个外出者。

玩家只能在没有外出者时换地图。每日补给仍在出发前发生，每个地点独立记录日期；不是每次打开菜单就重置全部世界。

## 结构和材料成为真实约束

`ShelterProgress` 保存结构、升级、修缮次数、事件和净补给。每子步磨损0.012×天气×等级系数，结构不降到负数；大风日系数1.5，等级系数为1−等级×0.12。

生产效率为结构系数×(1+等级×0.08)：结构低于20%取0.65，低于40%取0.85，其余1。生产还乘原人物效率；吃饭、睡觉、治疗始终不受生产降速拖慢。低结构不封死工作台，因而仍能修复，避免维修设施先坏后无法维修的死锁。

修整现在开工扣1材料，完成结构+18；中断退料且不修复。升级共三级，费用与README一致，整份扣除后才增级与结构+12。它减少维护频率、缩短生产耗时，不生产食物、燃料或药品。升级不改变任务定义耗时，改的是每子步进度速率，因此正在工作的快照仍可验证。

旧存档已经开工的免费修整携带 `legacy_repair` 标记，允许其无已扣材料继续原练习。完成既不扣新材料也不修结构，取消不退新材料；随后清除标记。新任务绝不使用此例外，队列后续修整按新规则扣料。

## 事件不会替玩家作决定

每天进入新日历时，若当前没有待处理事件，按日期轮换四类选择；只存一个待处理事件，未处理就保留，后续日期不会静默覆盖它。界面标明该事件原日期、完整费用、收益与放弃后果。

接受先原子检查 / 扣除，再给予结果并清空待处理编号；缺料既不扣资源也不丢选择。放弃普通交易不扣物资；风前加固放弃的结构损失写在选择前。处理一次立即记账，存读档不会再次发放。

事件只有基地页面可以操作。探索时手册可看记录 / 设置，升级、交换、地图切换都禁用。关窗、暂停或离线都不会代替玩家处理事件。

## 天气影响可观察的危险

天气按地点本趟出发日期确定，准备窗口公告；当前探索过程保持一致，不会过午夜后突然加倍敌情。细雨听觉系数0.75、视距0.85；浓雾视距0.6、听觉不变；大风听觉0.85，阴天均为1。视锥绘制与模型使用同一组缩放，贴身约55范围不被天气隐藏。

绘图增加雨线、雾带与风迹；它们没有独立模拟时间。基地大风磨损按当前日历，和已出发地图天气保持到归来的规则分别显示。

## 记录与里程碑不强制终局

出发时记录实际携带装备，成功归来按每种资源 `max(0, 本次背包−出发携带)` 统计净补给。只有至少一份净补给才增加该地点成功次数；自带药品往返不能刷探索目标，遇难不计收益。

六项里程碑覆盖第一次补给、照顾生活、走遍三处、真实修缮、三级据点和第七天存活。它们只展示进展，不赠送无限资源、不触发安全阶段、不让游戏强制结算。日志保留最近16项据点记录，操作日志仍为最近4条。

## 验证边界

`test_long_term.gd` 包含三处真实步行 / 搜刮 / 返回、独立地点与中途存档、几何、天气感知、修缮 / 取消、升级费用 / 上限、生产与恢复差异、事件缺料 / 一次性、旧版探索 / 免费修整迁移、无效数据原子拒绝和偏好持久化。

`visual_long_term.gd` 用真实键鼠从手册选择诊所、带回水，再去机修厂带回材料、爬实际梯子、归来制作工具并支付升级，实际推进到第二天并处理事件。截图没有添加物资或瞬移，健康 / 饥饿随这段过程正常变化。

`persistence_long_term_process.gd` 用三个独立进程验证机修厂携带实际搜获物资、攀梯中途关窗保存，重启继续 / 归来 / 制作 / 升级 / 事件，再重启核对所有物资与地图。它证明状态连续性，不把自动化检查等同于长期乐趣或完整平衡已经验收。


## v0.6：经连续14天验证的照料与消耗

新增口渴和真实饮水，基础食物不再是水的唯一消耗来源。自动照料需逐人授权，复用派工 / 库存而不制造补给。每清晨只对超过有限保鲜容量的食物按15% / 25%损耗，并在选择前显示预计数量；升级提高容量，不能无限囤熟食。

有上限的角色成长保留原专长差异，五人上限与新来者费用让补员带来食物、饮水与设施压力；死亡造成可恢复的悲伤，不能自动用新人覆盖尸体。敌人稳身和推搡疲劳消除重复徒手控制的无限安全，仍保留前摇与可躲避风险。

`test_balance.gd` 从新局、原始库存出发，以实际按模型移动 / 搜索 / 战斗、派工、交易、升级和付费招募运行三人、逐步五人两套14天策略；不注入物资或生命。两个失败对照分别关闭探索与照料。结果、每日CSV和解释范围见[平衡报告](BALANCE_REPORT.md)。

## v0.7：长程与恢复

在原14天策略与失败对照之外，新增三人30天、逐步五人60天，以及一次明确的伤亡／低库存夹具后的12天恢复。全部日记录、终点库存、方法与边界见[长程报告](ENDURANCE_REPORT.md)。新手可按N重看真实行动目标；人物事件提供有限的情绪与关系帮助，不生产物资。

## v0.8：项目与后期余量

O页有恢复通讯、建立救护点、连接补给线，共九个阶段。建设与共享两日间隔的互助使用真实材料、药品等资源，保留应急量仍需玩家判断。五人60天策略完成三条路线并继续生存，期末材料13、药品9；上一版同长度的实际结果为材料72、药品57。新版策略同时规划项目和互助，完整投入、食物／饮水结果与比较方法见ENDURANCE_REPORT.md；不参与这些活动仍可能积累库存。
