# v1.3.2 白天 A/D 移动修复

旧版本只有夜间探索读取A/D，白天在避难所按键没有响应。这版为白天补上键盘控制，并保留鼠标移动。

- 白天和夜间：A/D或左右方向键左右移动，Shift奔跑。
- 白天：在实际楼梯口按W/S或上下方向键上下楼；沿真实楼梯移动，不跨楼板。
- 鼠标操作继续保留，松开移动键后停止；人还在楼梯中途时会完成当前落脚。
- 键盘接管会取消当前行动，未完成任务按既有规则退料一次，并释放工位。
- 暂停和菜单／制作／家园窗口阻止后台移动，正在编辑文本输入框时不控制人物。
- 在平地移动时，存档保存实际位置，不保存持续按键造成的临时目的地；松键读档不会继续漂移。
- 夜间手动移动先于鼠标攻击等指令处理，冷却中的鼠标攻击不会抢住A/D。

验证覆盖实际按键、反向和松键、Shift、楼梯、暂停、菜单阻挡、任务取消退料、工位释放及保存恢复。新增了导出程序的真实系统键盘检查，在白天实际按D向右、按A向左，再继续夜间搜索与返程。
