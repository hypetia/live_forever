# 正常游戏：白天生活，夜间分工，清晨结算

[下载Windows游戏](https://github.com/hypetia/live_forever/raw/refs/heads/downloads-v1.0.0/live_forever_v10_windows_x64.zip) · [全部下载](../downloads/README.md)

解压整个文件夹，双击LiveForever.exe。游戏离线运行，不需要Godot、Python、账号或服务器。验收包是另一个工具，只有主动运行windows_acceptance.cmd才会自动控制人物测试。

## 先照顾人，再结束白天

点击人物卡选人，左键地面行走，双击奔跑。跨层会走楼梯；右键取消行动，楼梯途中会先走到最近平台。

点床位直接休息、点餐桌直接吃饭。水桶要走过去才会消耗水1。点灶台选择做饭与批数，确认后人物去现场生产。一次做饭消耗生食1、水1、燃料1，完成获得熟食2；再让需要的人吃饭。不要把F→G→H当作自动排好的连串工作：新命令默认替换，按住Shift才追加。

R让选中者自行用药。医护帮助同伴需要P页分别选择施治者与接受者。重度饥饿先吃饭，药品不会替代食物恢复生命；伤势和感染仍能用药处理。

B选择建设，再点击绿色位置。初始只有一张床，建成额外床会增加夜间床眠名额，白天也能实际使用。雨水收集器与加固隔断分别改变收水与防守。材料扣除、走到现场、施工和完成是不同步骤；未完工取消退料。

首日08:00开局，后续06:00开始。20:00结束白天；提前结束需要确认，未完成工作退料，跳过的时段不会免费完成生产。

## 安排一夜

夜间界面先选地点，为每个人分配搜刮、守夜、床眠或地铺。每晚最多一名搜刮者；床眠不能超过实际床位。可全员留守，但仍会消耗一夜并结算防守与需求。

逐份选择携带物资。调整草案不扣库存，确认出发才扣；没有数量为负、免费装备或重复确认的第二次扣除。搜寻者14格、工匠／厨师12格、医护10格，每份物资占一格。

夜里点击地面走动，双击奔跑；点击容器会走过去搜索。A/D移动、W/S爬梯仍可使用。整理界面左边是容器、右边是随身背包，可逐份拿取和放回；F尽量全部拿走，Esc关闭。物资仍真实留在原容器或背包中，没有远程入库。整理时场景继续，空格可暂停。

点击敌人会靠近并挥击，J也可挥击；红色生命条与金色警觉不同。徒手推开显示0伤害；工具命中消耗一件、造成40伤害并击倒；挥空、被挡有明确结果。R用背包药品，B用背包水，I展开背包。

回到最左入口按T撤退。提前回来也直接进入清晨，不会给你同一晚第二次搜刮。06:00以后自动沿实际路线撤离，迟归增加疲劳与压力；只有到达入口才能带回物资。

## 清晨与长期

床眠恢复65疲劳，地铺35；守夜+28、搜刮+35，途中额外消耗另计。第3夜起可能遭袭，健康、疲劳、守夜人数与加固隔断影响结果。报告说明净收获、需求变化与损失，读档不会重新结算。

开始新白天后，优先处理归来者的食物、休息、伤势与感染。N查看故事与六项实际行动引导，O查看长期建设目标与邻里互助，M查看地点／据点／记录，P查看人物与照料授权。自动照料默认关闭，授权后会真实消耗基础物资，不自动用药或花工具。

F6保存、F9读档、F11全屏、Esc菜单；正常关窗先保存，再启动保持暂停。离线不消耗资源。Alt+Tab会暂停，返回后按空格继续。

v0.9旧档可迁移，无须重开；旧档正在外出时先完成该次外出，其他状态按当前时间接入新昼夜循环，转入分工时退回未完成白天任务的用料。首次迁移保存保留旧原件备份。
