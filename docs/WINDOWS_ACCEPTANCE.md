# Windows 真机验收

当前开发环境为Linux。Windows运行包已导出和校验，但本文件不代表已经做过Windows真机测试。Windows验收包使用相同游戏程序、独立LiveForeverAcceptance.exe和内置PowerShell，不需要安装Godot或Python；测试不会读取你的正常存档。

## 一键自动检查

解压整个Windows验收包，双击windows_acceptance.cmd。保持当前桌面会话可用，等待约30分钟；期间程序会自动切换窗口尺寸、全屏／窗口，并持续进行真实时间的派工、饮水、移动、搜索、战斗和撤退，不注入物资、生命或坐标。

自动检查包括：

- 1024×768、1280×720、1440×900、1920×1080；超过当前屏幕尺寸的项目记录为跳过，不能算通过。
- 保持画面比例、完整手册窗口、真实全屏与返回窗口模式。
- 30分钟实际经过时间、逐帧玩法推进、存活、补给归来、帧数／慢帧与定期内存采样。
- 真实Windows关窗消息、退出码、校验和存档、启动原运行包、实际系统F6键，以及库存／目标／故事不重复。
- 记录实际Windows版本、显卡／驱动及普通程序／验收程序SHA-256。

每次使用独立时间戳结果目录。acceptance-result.json是机器结果，desktop-report.json和四份日志保存细节。脚本失败时保留结果，最后只关闭自己启动的测试进程；不修改普通用户存档。短测可用PowerShell执行`./windows_acceptance.ps1 -Minutes 1`，但结果不会标记为完成30分钟验收。

## 人工检查单

自动脚本不能判断声音是否可闻或文字是否舒服。完成自动检查后，在普通运行包中检查：

| 项目 | 记录通过／失败与实际设备 |
| --- | --- |
| 程序双击启动，中文清楚，无缺字／乱码 | 待实测 |
| F11与设置复选框都能切换全屏并返回 | 待实测 |
| 每个受支持分辨率下，按钮可点、手册可滚动、边缘不裁切 | 待实测 |
| 移动／搜索／攻击响应，受击提示和返程距离可辨认 | 待实测 |
| 提示音、归来音可听，关闭提示音后静音，风声可开关 | 待实测 |
| Alt+Tab失焦暂停，返回后按空格继续，没有卡住的移动／搜索 | 待实测 |
| 正常保存退出后，再启动能恢复；旧版有效进度可迁移 | 待实测 |
| 连续游玩30分钟后操作正常，无明显卡顿恶化／窗口无响应 | 待实测 |

需要保留真实结果目录和人工检查记录，才能把对应Windows设备标为验收通过。Windows结果不能由Linux模拟结果代替。
