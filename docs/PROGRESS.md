# 开发进度 · v0.8 / 长期目标、资源循环与桌面验收

## 本轮交付

三个可选长期目标、九个阶段、带回基地才生效的勘查记录，以及共用两日间隔的三种邻里互助。项目与互助实际消耗库存，精确账目进入schema6；完成目标后继续生存，兼容schema1—5。

操作加入F11全屏、失焦暂停与持续输入释放、返程距离／楼上指引、实际受击色彩／数字／生命条与挥击弧。窗口保持比例，帧率上限60。普通游戏与验收程序分别导出，普通游戏离线运行；验收工具只在主动运行时自动测试，不读取正常存档。

## 真实长期结果

三人30天、五人60天及独立逆境恢复均通过。前两组从新局连续推进，不注入库存、生命、坐标或经验。五人60天完成三条路线，实际付出材料54、药品45等物资，仍需171次外出。期末材料13、药品9；v0.7同长度实际结果为材料72、药品57。食物、水、燃料、目标投入与每日曲线见[长程报告](ENDURANCE_REPORT.md)。

新版策略额外规划项目和互助，因此差异反映整套玩法变化；不能全归因于某一个配方。不参与可选活动仍可能囤积资源，也不代表所有玩家操作和策略都已平衡。

## 桌面与退出定位

Linux实际窗口检查1024×768、1280×720、1440×900、1920×1080、保持比例、完整手册、全屏和返回窗口。独立运行包做30分钟真实时间的持续派工／移动／搜索／战斗／返程、外部进程内存采样，再核对系统关窗与原程序重启。实际连续1800.026秒、74,371帧，18项桌面检查通过；预热后常驻内存约307.4—310.1 MiB，末次307.4 MiB。系统关窗、原程序重启和库存／目标／故事／暂停时间核对通过。最终数据见[桌面报告](DESKTOP_ACCEPTANCE.md)。

首次虚拟显示关窗超时已经定位：冷Xorg没有预先注册WM_DELETE_WINDOW，而Godot启动时只查询既有值。原探针到关窗才创建协议，导致消息未匹配。现在启动前正确初始化，并用一致窗口树和PID匹配避免临时窗口竞争。三个独立冷显示会话分别确认原子最初不存在，再通过系统键盘搜刮、返程、15秒内关窗和重启。详见[定位证据](EXIT_DIAGNOSIS.md)。

Windows已导出并校验PE x64／内嵌数据，一键PowerShell通过结构语法检查；当前环境只有Linux，Windows真机启动、音频、显示及连续运行仍须实际设备结果。用户选择方便长期维护的一键包方式，无需远程桌面或密码；运行及提供结果的方法见[正常游玩](PLAYING.md)和[Windows检查单](WINDOWS_ACCEPTANCE.md)。
