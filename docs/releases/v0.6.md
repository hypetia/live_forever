# 开发进度 · v0.6 / 长期平衡与人物系统

## 本轮交付

按用户要求，完成长期平衡与人物系统这一组功能：真实饮水、有限保鲜、默认关闭的逐人照料授权、有限成长、情绪 / 创伤、队友信任、共餐、医护援助、三位可招募者和最多五位存活者。原有三地点、实时探索、基地生产、维护 / 升级、天气 / 事件和正常保存退出继续保留。

提供Windows x64、Linux x86_64独立运行包与源码。Linux独立程序实际操作、关窗与重启验证；Windows使用匹配官方模板导出，尚未做Windows真机运行。历史版本和需求原文保留。

## 长期平衡的实际调整

首轮14天运行发现水容易囤积、徒手重复推搡过于安全，因而增加实际饮水与推搡限制，而非仅让时钟跳到第14天。

- 口渴每秒+0.045，水1降低60，80起降效、95起慢慢伤生命；有独立预警。基地P饮水，外出B只用背包水，喝掉的物资不再返库。
- 自动照料逐人授权、默认关闭，使用真实基础物资，复用排队 / 配方。已安排工作不被覆盖，不自动花药品 / 工具；缺料显示等待补给。外出前授权的留守照料可继续。
- 保鲜容量生食12 / 熟食6，每级增加4 / 2；每清晨只对超额部分损耗15% / 25%，向上取整。当前预计损耗提前显示，读档不重复扣。
- 徒手挥击疲劳+1.2，成功推开再+2.8；失衡1.6秒、稳身3.6秒不可续推，保留可躲避前摇。感染者生命仍40、最多5名，不线性涨血。
- 三人与逐步五人两套从新局、原库存开始的策略，连续模拟14×720秒并存活；不探索与不照料的对照分别真实失败。正向策略通过实际移动、搜刮、战斗、交易、制作、升级与付费招募获得物资，没有注入库存、生命、坐标或经验。

[平衡报告](../BALANCE_REPORT.md)包含每日CSV、图表、最终库存和策略解释。它证明这些策略在当前配置下可持续且仍需外出；不等同所有玩家操作、所有策略或长期乐趣已验收。

## 文件职责

- `PeopleCatalog`：六个固定身份、特质、来访时间与队伍上限。
- `CharacterState`：有限成长、情绪 / 口渴、授权、冷却与人物快照。
- `PeopleSystem`：照料、关系、伤亡、支持 / 医疗、招募、饮水 / 损耗与每日记录。
- 根节点 / 调度器：真实完成 / 死亡信号、动态角色 / 卡片与统一时间。
- `test_people.gd`、`test_balance.gd`、`visual_people.gd`、`persistence_people_process.gd`：真实功能、长期策略、界面与跨进程验证。
- `tools/balance_report.py`：从实际结果生成Markdown、CSV和图表；`tests/run_checks.py`可一键重跑。

## 当前边界

人物系统是六位固定身份、三位来访者与三个有限成长方向；没有程序生成无限人物、复杂剧情对白或大型殖民地。美术仍为原创几何画面，暂无完整剧情战役、枪械、多人、通用物理碰撞或多槽存档。Windows已导出，尚未真机验证。

完整操作见[README](../../README.md)，人物规则见[PEOPLE](../PEOPLE.md)，实际数值见[平衡报告](../BALANCE_REPORT.md)。上一轮记录见[v0.5](v0.5.md)。
