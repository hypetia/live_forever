# 开发进度 · v0.7 / 同伴故事、新手引导与长程验证

## 本轮交付

六位角色各一章个人故事，另有低信任争执与伤亡纪念，共八章。加入六项按真实行动记录的新手目标、可隐藏的下一步提示，以及N键／顶部按钮入口。全部选择、结果、参与者、时钟与引导进度纳入schema5存档，兼容此前schema1—4。

延长长期验证到三人30天、逐步五人60天，并新增实际生存三天后设置伤亡／重伤／低库存夹具、再实际推进12天的恢复验证。前两组从新局开始，不注入库存、生命、位置或经验；逆境夹具在报告中单独列明。

提供Windows x64、Linux x86_64运行包和源码。Linux独立程序做真实系统输入、搜刮归来、正常关窗和重启验证；Windows官方匹配模板导出，完成PE x64及内嵌数据校验，尚无Windows真机验证。历史压缩包与需求原文保留。

## 可玩的故事与引导

- 每章根据实际身份、加入时间、工作、补给归来、信任／压力或伤亡触发，每次最多一段待谈话，新章节至少间隔两个日历日。
- 每章提供付费与保留物资两条完整分支。界面提前说明成本和双方情绪／信任变化；缺料原子拒绝，不部分扣款。
- 谈话出现不抢暂停、不自动扣料，不限时、没有拖延惩罚；外出可阅读，回基地后才可处理。无法让已故同伴说话或复活。
- 结果一次性记录，不可重复刷收益。谈话不恢复饥饿、口渴、疲劳、生命或伤病，不代替照料。
- 认识队伍、进食、饮水、睡眠、带回净补给、维护据点六目标来自实际行动。预排任务、做饭用水、原装备往返不算；顺序不限，可隐藏提示并随时重看。
- 旧档从原有实际记录推导部分目标，不编造曾经选择过的故事或打开过的人物页。

## 验证

Godot4.6.3、Linux x86_64；图形在Xorg dummy／Mesa llvmpipe运行。主验证使用干净副本和独立用户目录，不读取玩家存档。

图形交互原118项加新故事17项，共135项。新套件真实键鼠打开N、切换提示、跳转人物，实际模拟两天工作和搜刮后点击林舟故事的付费选择，核对材料、一次性结果与完整可保存状态；截图不注入库存或坐标。

独立运行包的首轮虚拟X11探针在关窗时超过15秒期限；相同二进制的诊断复测及未修改探针的最终复测均关窗／重启通过，未证实原因。初次失败与复测日志均保留在构建产物中，该环境的间歇性超时仍待定位，不将复测通过描述为已修复原因。

14个持久化进程：原基地2、旧街3、机修厂3、人物3，另加故事3。故事探针先实际生存两天并保存待处理事件，下一进程读取并选择免费分支，再一进程核对结果、引导偏好、库存和不可重复奖励。

真实schema1／2／3／4旧样本均迁移。新增v0.6四人外出样本由归档程序实际生存三天、付费招募后生成，迁移后的首次保存保留旧文件原字节备份。
