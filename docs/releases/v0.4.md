# 开发进度 · v0.4 / 第四轮交付

## 当前可以玩到什么

这一轮完成实时外出、危险与医疗、探索存档和旧存档迁移，接通 **基地消耗 → 选一人外出 → 潜行 / 搜刮 / 应对感染者 → 亲自回入口 → 带回补给与伤势 → 做饭 / 休息 / 治疗** 的最小生存闭环。

它承接 v0.3 的基地生活与存档，落实原计划 M3 探索，并把 M4 存档扩展到探索全过程。目前可玩的是一个地点的 MVP 原型，还不是内容完整、平衡完成的长期无尽游戏。需求原文保持不变。

## 本轮成组交付

- 原创“河湾旧街”：两层路线、连续攀梯、六个资源容器、三个初始感染者、横向跟随视野和独立探索 HUD。
- A/D 直接移动，Ctrl 潜行，Shift 奔跑，E / 鼠标按住搜索，W/S 上下梯；不以文字派遣代替实时游玩。
- 出发准备显示状态和敌情，可选携带工具 / 药品。确认时整份装备校验成功才扣除和取消出发者基地任务；取消或缺料保留原工作。
- 一人外出，两人继续基地队列；共享需求与时间，外出固定1x，暂停两边都冻结，归来恢复基地速度并暂停。
- 10格背包，装备也占空间；装不下的仍在容器，可逐份丢弃。只有地面左侧入口才能撤退、入库；远处 T 只提示方向。
- 感染者巡逻 / 听声调查 / 警觉追击 / 有前摇扑咬；潜行掩体、噪声和朝向有作用，敌人不跨层咬人。徒手暂时推开，工具成功破锁或击倒时按件消耗。
- 咬伤造成生命损失、伤势与感染，持续到基地；途中药品急救、基地餐桌治疗。重伤降效、感染发展和预警接入原有生存规则。
- 同一天容器和击倒状态持久；新一天在下次出发前只补充两处轮换容器、公告感染者迁入，最多四名、生命固定，不在活动地图突然刷新。
- 探索全过程 F6 / 自动 / 正常关窗保存，搜索、攀梯、双方攻击前摇、背包和场景余量可恢复。v0.3 真实 schema 1 存档迁移到 schema 2，不重开、不重扣用料、不赠送药品。
- 保留并回归基地六任务、四设施 FIFO、三项队列、生存 / 昼夜 / 死亡、本地单槽 / 校验和 / 备份 / 损坏保护。

- 干净副本首次导入、主场景启动、上述六套实际执行完成：通过，无引擎 / 脚本错误。
- 基地图形36项、探索图形36项，共 **72项检查通过**。包含真实按键按住 / 松开、鼠标准备与装备选项、搜索按钮、两层移动、途中 F6 / F9、暂停、入口归来和基地生活循环。
- 基地双进程验证：正常关窗处理保存已扣料的做饭任务，独立重启恢复并完成，只产出一次。
- 探索三进程验证：携药出发，真实移动并搜索到一半后关窗处理保存；独立重启暂停恢复、继续搜刮并步行撤退；第三次启动检查背包返库与箱子消耗只计算一次。
- 用原 v0.3 源码实际生成做饭中途旧档，检查 v1→v2 迁移、继续完成、升级备份保留原字节，以及主档损坏后从旧备份迁移恢复的提示。
- 库存 / 队列 / 枚举 / 文本严格比较；JSON 连续浮点状态比较容差1e-6，不把末位表示差异当作状态丢失。

图形验证发现并修复准备窗口文字与装备选项重叠，改用容器布局并加入实际矩形检查；另修复击倒敌人仍留有警觉造成持续警报。软件显示驱动提示不支持切换 V-Sync，属于宿主警告，未影响验证。

## 仍然存在的限制

- 一个探索地点、固定三人 / 六处容器、基础 AI；每日轮换有限，尚无多地点、招募、事件 / 剧情、最终长期平衡或多存档槽。
- 工具是按件消耗的破锁 / 战斗用品；修整仍为无收益练习，没有真正设施耐久、升级或电力系统。
- 原创几何占位画面，没有正式角色动画、音效 / 音乐；基地固定路点，探索固定楼层 / 梯子，没有跳跃、通用物理碰撞、枪械、复杂墙体视线或多人外出。
- 无云存档、铁人模式；强制杀进程 / 编辑器停止不保证保存，正常关窗处理路径和 F6 已验证。
- **Windows 真机、Windows EXE / Web 导出尚未验证或交付**；当前提供 Godot 源码工程。
