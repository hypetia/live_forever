# 开发进度 · v0.5 / 第五轮交付

## 当前交付

按用户继续做成成品的要求，这轮扩大为一组完整改进：**三地点探索 + 真实修缮 / 升级 + 每日事件 / 天气 + 可选目标 + 游戏内指南 / 设置 + 桌面独立运行包**。原有基地、战斗、治疗、死亡和存档继续可玩。

提供Windows x64、Linux x86_64运行包与源码；用户不必为了试玩安装编辑器。Linux已实际运行验证；Windows已用匹配的官方模板导出并检查格式，尚未做Windows真机运行。当前版本仍需更多长期游玩与内容打磨，不能把“完美成品”作为已验证事实。

上一轮进度保留为 [v0.4记录](v0.4.md)，M01—M04源码包不覆盖。需求原文不修改。

## 本轮实际新增

- 三处原创地点，共18个容器：河湾旧街侧重食物 / 水，雨杉诊所侧重药品，北堤机修厂侧重材料 / 燃料 / 工具。各自路线长度、平台 / 梯子、掩体、巡逻、场景配色与物资不同。
- 地点独立持久化：切图不能刷回资源；新日只在出发前执行该地点两容器轮换、公告敌人迁入。数量最多5、生命固定40，不在活动玩家身边突然刷新。
- 准备窗口可选目的地，显示风险、天气、状态和装备；街区手册可选地图并进入同一准备流程。
- 修整消耗真实材料，完成结构+18，取消退料、不修复；结构缓慢磨损、低于40% / 20%影响生产，恢复任务不降速。
- 三级据点升级，整份扣材料 / 工具 / 燃料 / 药品；提高生产速度、减慢磨损，仍需搜刮补给。
- 每日四类轮换事件：接雨水、换物者、风前加固、邻街求助。费用 / 收益 / 放弃后果先显示，缺料不扣部分，未处理保留，不能重复领取。
- 阴天 / 细雨 / 浓雾 / 大风，实际影响敌人感知；视锥采用同一组系数，贴身范围始终能察觉。天气有画面和出发提示。
- 六项可选里程碑与16条据点记录；从归来背包扣除自带装备再统计净补给，空跑不算探索。第七天和目标达成都不强制结局。
- M街区手册、F1操作指南、Esc菜单；音量 / 提示音 / 原创合成风声 / 全屏、保存退出，偏好独立持久化。
- schema 3，兼容真实v0.3 / v0.4旧档；当前外出原样迁入旧街，旧版免费修整完成 / 取消保留旧语义，不会赠材料或新增维修收益。
- 官方引擎与字体许可随包提供；运行包嵌入游戏数据，剔除测试 / 开发截图，源码包含可重复验证与导出配置。

图形三套：基地36项、探索36项、长期玩法24项，合计 **96项检查通过**。真实鼠标 / 键盘覆盖手册选择诊所、搜索带水返回、选择机修厂、搜材料 / 燃料、实际爬梯、走回入口、用带回材料制作工具并付费升级、推进到第二天后付费处理事件、指南与设置开关。

8个独立持久化进程：

1. 基地2进程：已扣料做饭经正常关窗处理保存，独立启动恢复后只产出一次。
2. 旧街3进程：半程搜索关窗保存，恢复继续搜刮并走回入口，再次启动核对库存 / 容器只变化一次。
3. 机修厂与长期状态3进程：携实际搜获物资攀梯中途关窗，独立启动恢复、下梯 / 返回、制作工具 / 升级 / 第二天事件，第三次启动核对精确物资、等级、事件与独立地图记录。

兼容样本由归档原程序真实生成：schema1做饭中途、schema2外出搜索中途、schema2免费修整中途。验证原材料 / 进度不重扣、无免费药品或材料、原始字节保留升级备份；坏旧字段安全返回失败，不抛脚本异常。

独立运行检查发现旧的Node通知处理没有接上真实系统关窗；现已直接连接主Window的 `close_requested` 信号，退出按钮与持久化进程探针统一使用该信号，系统级探针另发送真实X11窗口关闭请求。

本轮还修复了音频快速退出时播放对象未释放的问题；不再在关闭环境音时启动循环播放，退出显式停止，并给混音线程120毫秒完成缓冲清理。软件显示驱动的V-Sync切换警告为宿主能力提示。

## 尚需继续打磨

- 三地点和四类事件仍是有限内容，不等同于无限丰富的长期玩法；没有剧情战役或其他势力系统。
- 固定三位幸存者，暂未加入招募、替补、人物成长与情绪系统；死亡后的分工后果已经保留。
- 原创几何场景与基础动画、提示音 / 风声；没有正式角色美术、完整音效库或配乐。
- 没有跳跃、通用物理碰撞、枪械、复杂墙体视线、多人外出或联网。
- 据点是整体结构 / 等级，尚无独立房间扩建、每件设施独立耐久或电力系统。
- 单槽与备份；没有多槽 / 云存档 / 铁人模式。强制杀进程不保证保存，正常关窗处理与F6已验证。
- Windows已导出，尚未做真机测试；未提供macOS / Web版。
